# AsyncFlow — Задачи

Страница задач с фильтром по приоритету и созданием задачи через модальное окно.
React 19 + TypeScript (strict) + Vite, без бэкенда.

**Демо:** https://asyncflowtest.vercel.app/

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # Vitest + Testing Library
npm run lint       # oxlint
npm run typecheck
npm run build
```
